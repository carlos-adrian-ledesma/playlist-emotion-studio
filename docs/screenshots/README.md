# Playlist Emotion Studio v1.6.1 — Screenshots

These six screenshots were captured from the **actual Tkinter application** at version **1.6.1**.

- **Source:** Same `playlist_emotion_studio.py` Git blob as the public `main` repository (`4b2108c96ac3dcbe68ab263299703b08bd8aa71a`).
- **Environment:** Isolated Linux virtual display (Xvfb), 1590 × 990 capture area. These are not Windows compatibility-test screenshots.
- **Database:** A disposable copy of the public sanitized SQLite baseline, populated exclusively with fictional songs, artists and a demo playlist for display purposes.
- **External services:** StarMaker, YouTube and Spotify requests were not run for these screenshots. Empty platform counters are intentional; they do not demonstrate successful API connection.
- **Privacy:** No real user library, API keys, private accounts, tokens, or operational SQLite databases are included.
- **Scope:** Screenshots are authentic UI renderings. They do not prove that every feature works or that the application has passed a complete Windows QA suite.
